# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use the
repository's **Security → Report a vulnerability** flow so the report and any
supporting material remain private while it is investigated.

Include the affected component, a minimal reproduction, the observed impact,
and the macOS and MERRICK versions involved. Do not include real API keys,
voiceprints, private memory, or other personal data.

## Supported version

Security fixes target the latest commit on the default branch until tagged
releases begin.
